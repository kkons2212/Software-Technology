# UC-06: Visitor Payment & Visiting Session Activation

| Field | Content |
|---|---|
| Use Case Number: | UC-06 |
| Use Case Name: | Visitor Payment & Visiting Session Activation |
| Actor(s): | Visitor (Primary), Payment Gateway (Secondary) |
| Maturity: | Focused |
| Summary: | The Visitor pays a fixed fee for the museum tour pass via Domestic VietQR or International Card (or restores an existing session). Once payment is confirmed by the Payment Gateway via Webhook, the system activates a 24-hour Visiting Session to unlock full POI details and audio guides. |
| Basic Course of Events: | **Actor Action**<br>1. The use case begins when the Visitor selects "Unlock Audio Guide Service" from the home screen or a locked exhibit.<br><br>**System Response**<br>2. The system displays the fixed service fee, payment options (VietQR or Card), and a "Restore Tour Session" option.<br><br>**Actor Action**<br>3. The Visitor selects a payment method (VietQR or Credit/Debit Card). A1.<br><br>**System Response**<br>4. The system sends a request to the Payment Gateway to generate a payment order. E1<br>5. The system displays the corresponding payment interface (VietQR code or Card input form).<br><br>**Actor Action**<br>6. The Visitor completes the payment on the displayed interface.<br>7. The Payment Gateway confirms the transaction and sends a Webhook notification to the system. E2<br><br>**System Response**<br>8. The system verifies the Webhook signature, records the transaction as PAID, and creates an active Visiting Session (valid for 24 hours) with a unique Session Code.<br>9. The system stores the session token on the Visitor's device, unlocks all exhibits and audio guides, and redirects the Visitor to the tour view. |
| Alternative Paths: | **A1: Visitor Resumes an Existing Session (Restore Access)**<br>**Actor Action**<br>1. At step 2, the Visitor selects "Restore Tour Session" and enters their previous Session Code.<br><br>**System Response**<br>2. The system verifies that the Session Code exists and has not expired. E3<br>3. The system restores the active session state without requiring a new payment.<br>4. Return to step 9 of the Basic Course of Events. |
| Exception Paths: | **E1:** At step 4, if the Payment Gateway is unreachable, the system displays a connection error message, allows the Visitor to retry, and returns to Basic Flow Step 2.<br><br>**E2:** At step 7, if the payment fails (insufficient funds, cancelled, or expired), the Payment Gateway notifies the system. The system updates the payment status, displays a failure notification to the Visitor, and returns to Basic Flow Step 2.<br><br>**E3:** In path A1 (at step 2), if the Session Code does not exist or has expired (> 24 hours), the system informs the Visitor that the session is invalid or expired and returns to Basic Flow Step 2. |
| Extension Points: | None. |
| Triggers: | Visitor selects "Unlock Audio Guide Service" or attempts to play a locked exhibit audio guide. |
| Assumptions: | The museum charges a single fixed fee per visiting session; the Visitor's browser allows storing the session token in localStorage. |
| Preconditions: | The Visitor has an active internet connection and is accessing the web application on their mobile browser. |
| Postconditions: | For new payments, a transaction record is saved with status PAID and a 24-hour VisitingSession is activated. For restored sessions, full access to POI details and audio guides is unlocked on the Visitor's device. |
