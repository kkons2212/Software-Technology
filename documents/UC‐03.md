# UC-3.1: Edit POI Content & Metadata

| Field | Content |
|---|---|
| Use Case Number: | UC-3.1 |
| Use Case Name: | Edit POI Content & Metadata |
| Actor(s): | Admin |
| Maturity: | Focused |
| Summary: | Allows Museum Staff or Admin to select an existing exhibit (POI) and edit its display text content and media images. |
| Basic Course of Events: | **Actor Action**<br>1. Museum Staff navigates to the POI management list and selects an exhibit to edit.<br><br>**System Response**<br>2. The system retrieves POI data and displays the edit form with current metadata and thumbnail.<br><br>**Actor Action**<br> 3. Museum Staff updates exhibit details such as title, detailed description, category, or media image.**A1**<br>4. Museum Staff clicks "Save Changes".<br><br>**System Response**<br>5. The system validates all input fields.**E1** <br>6. The system updates the POI content in the database, and displays a success notification. |
| Alternative Paths: | A1: Staff cancels the editing session.<br>**Actor Action**<br>1. The system prompts for confirmation if unsaved changes exist.<br><br>**System Response**<br>2. Staff confirms cancellation, and the system discards all modifications.<br>3. Return to step 1 |
| Exception Paths: | E1: required field is empty <br>**System Response**<br>1. The system highlights the empty fields, displays an error message, and retains entered data.<br>2. Return to step 3 |
| Extension Points: | None. |
| Triggers: | Admin wished to editing the content of a POI. |
| Assumptions: | None. |
| Preconditions: | Staff is authenticated with Admin or Staff privileges; the POI exists in the database. |
| Postconditions: | Updated exhibit content and media details are saved in the database. |

# UC-3.2: Configure GPS Coordinates & Geofence Radius

| Field | Content |
|---|---|
| Use Case Number: | UC-3.2 |
| Use Case Name: | Configure GPS Coordinates & Geofence Radius |
| Actor(s): | Admin |
| Maturity: | Focused |
| Summary: | Allows Museum Staff or Admin to configure an exhibit's precise GPS geographical coordinates (latitude, longitude) and proximity geofence radius via an interactive map picker or manual coordinate input for automated outdoor visitor detection. |
| Basic Course of Events: | **Actor Action**<br>1. Museum Staff selects an existing exhibit to configure its location.<br><br>**System Response**<br> 2.The system displays the current GPS pin plotted on an interactive map.<br><br>**Actor Action**<br> 3. Museum Staff adjusts the exhibit's GPS position by clicking or dragging the pin on the interactive map, or typing latitude/longitude directly into the coordinate fields.<br><br>**System Response**<br>4. The system updates the map pin in real time, displays the circular geofence boundary.<br><br>**Actor Action**<br>5. Museum Staff adjusts the proximity trigger radius (e.g., default 15 meters).<br>6. Museum Staff clicks "Save Changes".<br><br>**System Response**<br>7. The system validates all input fields.**E1**<br>  8.The system updates the GPS coordinates and geofence radius in the database, invalidates existing route caches, and displays a success notification. |
| Alternative Paths: | None. |
| Exception Paths: | E1: The selected GPS coordinates fall outside the designated museum grounds (not in museum border)<br>1. The system displays a boundary warning and prevents submission.<br>2. Return to step 3 |
| Extension Points: | None. |
| Triggers: | Admin wished to editing the location of a POI. |
| Assumptions: | None. |
| Preconditions: | Staff is authenticated with Admin or Staff privileges; the POI exists in the database. |
| Postconditions: | Updated GPS coordinates and geofence radius are saved; the visitor outdoor map updates the POI pin and walking directions accordingly. |
