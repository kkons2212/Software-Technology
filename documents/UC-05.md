# Use Case Specification: UC-05

---

| Field | Content |
| :--- | :--- |
| **Use Case Number:** | **UC-05** |
| **Use Case Name:** | **Review & Edit Translated Content & Audio Guides |
| **Primary Actor:** | Admin / Museum Staff |
| **Secondary Actor:**| TTS Service (edge-tts) |
| **Maturity:** | High |
| **Summary:** | Allows museum staff to review, edit, regenerate audio via TTS, and publish translated exhibit content for visitors.    |
| **Reference: Business Rules:** | **BR-01:** Only approved translations shall be publicly displayed to museum visitors.<br>**BR-02:** When translated text content is edited, the corresponding Audio Guide status shall be marked as requiring regeneration.<br>**BR-03:** Audio files generated by `edge-tts` must match the designated language code. |

---

### Basic Course of Events

| Actor Action | System Response |
| :--- | :--- |
| **1.** Admin accesses the Translation Management module. | |
| | **2.** The system displays the list of translations along with filter options (by Language, Approval Status, Exhibit). |
| **3** Admin selects a translation from the list and clicks "Preview Audio Guide" to inspect. [A1, A2, E2] |  |
| | **4.** The system plays the current Audio Guide file and displays the translation details. [E1] |
| **5** Admin verifies that both text and audio content meet quality standards, then clicks "Approve & Publish". | |
| | **6.** The system updates the translation status to "Published" and synchronizes it with the visitor-facing application. |

---

### Alternative Paths
### A1: Edit Text Content and Regenerate Audio Guide 
| Actor Action | System Response |
| :--- | :--- |
|1. Selects "Edit" and updates the text content .| |
| |2. Saves the updated text and marks the audio status as "Pending Update". |
|3. Clicks "Regenerate Audio Guide" . | |
| |4. Calls `TTS Service (edge-tts)` to generate and save the new audio file. |
|5. Previews the newly generated audio file. | |
| | 6. Proceeds to **Step 5** of the Basic Course to Approve & Publish. |

### A2: Regenerate Audio Guide Without Editing Text (US-05.4)
| Actor Action | System Response |
| :--- | :--- |
|1. Directly clicks "Regenerate Audio Guide". | |
| |2. Calls `TTS Service (edge-tts)` to generate a new audio file.|
| |3. Proceeds to **Step 5** of the Basic Course to Approve & Publish. |


### Exception Paths
### E1: TTS Service (`edge-tts`) Connection Failure
* **System Action:** Displays an error message: *"Failed to connect to speech synthesis service. Please try again later."*, retains current data, and prompts the user to retry.

### E2: Missing Audio Guide File
* **System Action:** Displays a notification: *"Audio Guide file does not exist for this translation"*, and prompts Admin to click "Regenerate Audio Guide".

### Supplementary Information

| Field | Content |
| :--- | :--- |
| **Extension Points:** | - **Generate_Audio_On_Edit:** Triggered when Admin successfully updates translation text (US-05.3 $\rightarrow$ US-05.4).<br>- **Publish_Content:** Triggered after audio review is completed and approved for publishing. |
| **Triggers:** | Admin / Museum Staff navigates to the Translation & Audio Guide Management module. |
| **Assumptions:** | Raw machine-translated content has already been initialized by the system. |
| **Preconditions:** | - Admin / Museum Staff is authenticated with appropriate role permissions.<br>- `edge-tts` service is operational. |
| **Post Conditions:** | Translated text and Audio Guide files are updated, approved, and ready for public serving on the museum app. |
