| Field | Value |
| :--- | :--- |
| **Use Case Number:** | **UC 5** |
| **Use Case Name:** | **Monitor Traffic & System Health** |
| **Actor(s):** | Admin / Museum Staff |
| **Maturity:** | Completed |
| **Summary:** | Allows the Admin or Museum Staff to monitor visitor traffic, Audio Guide usage behavior, and system health status through analytical and monitoring dashboards. |
| **Basic Course of Events:** | 1. Admin/Staff accesses the "Traffic & System Health" feature from the management Dashboard.<br>2. The system collects analytical data from the Analytics & Logging Module.<br>3. The system aggregates GPS Telemetry data, Geofence events, and Audio Guide usage statistics.<br>4. The system displays the visitor traffic Dashboard including:<br>&nbsp;&nbsp;&nbsp;&nbsp;- Number of GPS Proximity triggers.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Visitor density heatmap.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Most accessed POIs.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Audio Guide usage statistics by language.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Average interaction time at each POI.<br>5. Admin views the traffic data and switches to the "System Health" tab.<br>6. The system displays the system health Dashboard including:<br>&nbsp;&nbsp;&nbsp;&nbsp;- Telemetry and API latency.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Audio streaming performance.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Storage and caching status.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Database performance.<br>&nbsp;&nbsp;&nbsp;&nbsp;- Status of AI services (Translation, TTS).<br>7. Admin reviews visitor traffic and system health metrics, evaluates operational status, and determines whether further actions are required.<br>8. The use case ends. |
| **Alternative Paths:** | **A1. Filter Analytical Data:**<br>1. Admin selects a specific zone, POI, or time range to view.<br>2. The system retrieves data based on the applied filters.<br>3. The system updates the heatmap, charts, and corresponding statistics.<br>4. Resume at Step 4 of the Basic Course of Events.<br><br>**A2. Export Report:**<br>1. Admin selects "Export Report".<br>2. Admin chooses CSV or JSON format.<br>3. The system generates traffic and system statistical reports.<br>4. The system provides the file for download.<br>5. Resume at Step 7 of the Basic Course of Events.<br><br>**A3. Real-Time Monitoring:**<br>1. Admin enables the "Live Auto-Refresh" mode.<br>2. Admin configures the data refresh interval.<br>3. The system automatically updates the Dashboard in real-time.<br>4. Returns to Step 4 or Step 6 of the Basic Course of Events. |
| **Exception Paths:** | **E1. Data Aggregation Timeout:**<br>1. The system fails to process analytical data within the permitted time frame.<br>2. The system displays data from the most recently saved record.<br>3. The system displays a notification: *"Real-time data is temporarily delayed; displaying cached data."*<br>4. The system continues to retry updating later.<br><br>**E2. Storage Capacity Threshold Exceeded:**<br>1. The system detects that storage usage exceeds the warning level.<br>2. The system marks the status as WARNING or CRITICAL.<br>3. The system displays an alert to the Admin.<br>4. The use case continues.<br><br>**E3. AI Services Degraded or Down:**<br>1. The system detects unstable performance in Translation or TTS services.<br>2. The system marks the status as DEGRADED or OFFLINE.<br>3. The system logs the event into the Audit Log and displays an alert to the Admin.<br>4. The use case continues. |
| **Extension Points:** | - **Automated Alert Dispatch:** Triggered to send emails or notifications when visitor density or system errors exceed allowable thresholds. |
| **Triggers:** | Admin or Museum Staff accesses the "Traffic & System Health" screen. |
| **Assumptions:** | - Visitors' devices have granted GPS permissions.<br>- The system is actively collecting telemetry from the visitor mobile application.<br>- POIs have been configured with valid Geofences. |
| **Preconditions:** | - The user is logged in with administrative privileges.<br>- The Analytics & Logging Module is active and recording telemetry data. |
| **Postconditions:** | - Visitor traffic and system health dashboards are successfully displayed.<br>- Any alerts or anomalies are recorded within the system.<br>- Admin has access to traffic analytics and system health information for operational decision-making. |
