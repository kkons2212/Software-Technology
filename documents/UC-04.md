| Field | Content |
| :--- | :--- |
| **Use Case Number:** | **UC-04** |
| **Use Case Name:** | Edit POI Information & GPS Geofence Positioning |
| **Actor(s):** | Admin / Museum Staff (Primary), Interactive Map / Geolocation Service (Secondary) |
| **Maturity:** | Focused |
| **Summary:** | Museum Staff or Admin selects an existing exhibit (POI) to edit its display content (title, description, images) and configure its precise GPS geographical coordinates (latitude, longitude, and proximity geofence radius) via an interactive map picker or manual coordinate input for automated outdoor visitor detection. |
| **Reference: Business Rules:** |  |

---

### Basic Course of Events

| Actor Action | System Response |
| :--- | :--- |
| **1.** Museum Staff navigates to the POI management list and selects an exhibit to edit. | |
| | **2.** System retrieves POI data and displays the edit form with current metadata, thumbnail, and the current GPS pin plotted on an interactive map. |
| **3.** Museum Staff updates exhibit details (title, detailed description, category, or media image). | |
| **4.** Museum Staff adjusts the exhibit's GPS position by clicking or dragging the pin on the interactive map, or typing latitude/longitude directly into the coordinate fields. **[A1]** | |
| | **5.** System updates the map pin in real time, displays the circular geofence boundary, and validates that coordinates fall within museum site boundaries. **[E1]** |
| **6.** Museum Staff adjusts the proximity trigger radius (e.g., default 30 meters) and clicks "Save Changes". | |
| | **7.** System validates all input fields, updates the POI and GPS coordinates in the database, invalidates existing route caches, and displays a success notification. **[E2]** |

---

### Alternative Paths

#### **A1. Discard Changes**
| Actor Action | System Response |
| :--- | :--- |
| **1.** Staff cancels the editing session. | |
| | **2.** System prompts for confirmation if unsaved changes exist. |
| **3.** Staff confirms cancellation. | |
| | **4.** System discards all modifications and returns to the POI list view. |

---

### Exception Paths

* **E1:** At step 5, if the selected GPS coordinates fall outside the designated museum grounds (latitude not in [lat_min, lat_max], longitude not in [lng_min, lng_max]), the system displays a boundary warning and prevents submission.
* **E2:** At step 7, if a required field is empty or database saving fails, the system highlights the erroneous fields, displays an error message, and retains entered data.

---

### Supplementary Information

| Field | Content |
| :--- | :--- |
| **Triggers:** | Museum Staff needs to update exhibit descriptions, replace photos, or relocate/recalibrate an exhibit's GPS location on the map. |
| **Assumptions:** | Museum staff uses an admin workstation/desktop with an updated web browser supporting interactive maps (Leaflet / OpenStreetMap). |
| **Preconditions:** | Staff is authenticated with Admin or Staff privileges; the POI exists in the database. |
| **Postconditions:** | Updated exhibit details and GPS coordinates/geofence radius are saved; visitor outdoor map updates the POI pin and walking directions accordingly. |
